# MoonMatBridge v0.0.21

完善文件宿主的关闭路径，成功及异常场景均只关闭一次；名称解码直接使用受控字节视图，公开结果继续拥有自身数据。

CSC 索引块使用连续偏移和 32 位写入，减少逐项游标更新及位转换，保持原始索引顺序和容量。性能报告以固定 v0.0.19 提交为对照，保留全部样本。

新增真实 Octave UTF16 非 BMP 生产案例，独立核对三个 Unicode scalar 对应四个存储单位及文件维度，再执行 native、Node 与 Octave 的完整往返验证。

为四个已知 Octave 8.4 生产特例提供独立的字节级诊断：分别记录矩阵声明长度与实际长度、数组类编号与 CSC 负载的对应关系，以及各工具实际消费结果。标准解析规则保持严格。

名称编解码、公共 API 基线及生产特例报告随发行资产提供。具体测试、工具版本、哈希和执行结果见 verification/reports 中本版本的回执。
