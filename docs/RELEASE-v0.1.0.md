# MoonMatBridge v0.1.0

本版统一交付 MAT Level 5 基本类 1—15 的数据级读写，覆盖 cell、struct、char、legacy object 类名与字段数据、数值和 CSC，以及递归混合文件。支持大小端读取、压缩、显式 UTF8/Latin1 名称策略、精确与容差比较、无损树快照及 NPY 数值互通。

文件源支持 1 GiB 输入与累计解压额度，默认所选规范 MAT 大小 64 MiB、元数据 8 MiB、读取块 1 MiB；未选变量完整校验，公开结果拥有自身数据。名称编码说明、真实 Octave 非 BMP 文件及来源记录随公开包提供。

三目标检查、构建和测试，独立 SciPy/NumPy、真实 Octave 双向互操作，以及公开安装和三个科研流程构成发布检查。现有接口和报告格式保持兼容；完整生产运行时代码与已测 v0.0.21 一致，直接使用固定 v0.0.19 对照及全部原始样本。

GitHub 与 Mooncakes 统一使用 v0.1.0。分块写入、多 GiB 文件和 HDF5 MAT v7.3 后续单独推进。
