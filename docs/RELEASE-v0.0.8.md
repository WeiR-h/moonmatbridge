# MoonMatBridge v0.0.8

新增 `read_selected`、`inspect_roots`、`MatRootInfo` 和 `roots INPUT.mat`。`select` 保持请求顺序，减少未选数据树与负载分配，同时保留所有变量的结构、类型转换、稀疏索引、字符编码、资源额度和压缩校验。

空选择、遗漏的损坏变量及未知类型仍明确报错，不提供跳过校验模式。输入文件仍整体在内存，压缩根变量仍须有界解压；不宣称随机磁盘读取或压缩流内部直接跳转。

公开消费者验证新增 API；独立 SciPy 核对 15 类混合文件的元数据和选择结果，实际 GNU Octave 流程继续执行。UTF8 扫描与标准解码器作边界和随机字节差分验证。

同机 v0.0.5 对照报告随版本提供，分开报告核心、命令行和峰值内存。安装：`moon add WeiR-h/moonmatbridge@0.0.8`。完整标准变体终点尚未全部验证，保持 0.x。

正式复测：16 个各 1 MiB 变量中选择一个，native 核心提速约 **14.2 倍**、峰值下降 **38.3%**；JS 提速约 **10.3 倍**、峰值下降 **48.1%**。native 的峰值下降仍未达到自定 **40%** 目标，性能目标未全部完成。四组写入目标继续通过，24 个固定操作/宿主组合没有超过 10% 的退化。原始样本、首次退化记录与修复后的测量均保留。
