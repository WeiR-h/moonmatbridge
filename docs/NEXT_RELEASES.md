# 当前开发安排

v0.1.10 固定交付基线与证据入口；随后依次推进压缩读取、压缩写出、JS 内存载荷复制和科研交付收口。每版保持公共接口与额度，分别验证三目标、独立工具和公开发行。性能以固定 v0.1.9 为主对照，并核对上一稳定版；历史测量保持原版本。

## Windows 便携程序路径修复

候选源码统一 Windows 原生程序的长路径处理，覆盖整文件读取、分块读取、直接写入和分块写入。Windows CI 的便携检查使用含中文和空格的深层目录，核对文件比较、已有文件保护及临时文件清理。公开 v0.1.11 仍按 [科研流程说明](SCIENTIFIC_WORKFLOWS.md) 使用较短的输出路径。
