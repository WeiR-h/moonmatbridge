# MoonMatBridge 开发路线与执行记录

## 当前执行：v0.1.1—v0.1.5

以 v0.1.0 为基线，先升级固定 moonc 0.10.16 与标准库，再完善跨平台验证、使用文档和分块写出。每版独立验证、固定提交、发布 GitHub / Mooncakes 并公开复验。

| 版本 | 工作 | 完成检查 |
| --- | --- | --- |
| v0.1.1 | 固定新编译器、实际版本门禁、旧消费者回归 | 三目标、独立工具、CI 与新环境性能基线 |
| v0.1.2 | Windows/Linux CI、覆盖报告、当前文档索引 | 最小示例及三个公开科研流程 |
| v0.1.3 | MatSink、WriteLimits、未压缩分块输出 | 同版内存写入字节一致、短写与失败原子性 |
| v0.1.4 | 增量压缩输出、32 KiB 窗口和长度回填 | 独立 zlib / SciPy / Octave 消费 |
| v0.1.5 | 固定大树写入基准、科研流程整合 | 新旧路径及公开资产复验 |

输入树仍驻留内存；输出工作缓冲有界。新写出额度独立配置，原内存与文件读取额度保持。性能历史保留，新结果同时绑定生产源码、编译器、标准库及构建环境。文件到文件流式转换、多 GiB、网络输出和 HDF5 后续规划。
