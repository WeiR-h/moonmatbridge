# MoonMatBridge v0.0.14

压缩读取使用位缓冲和 9 位 Huffman 短码表；长码保留逐位回退路径。压缩根直接在有界输入区间解码，按 MAT 头预分配展开缓冲，减少临时复制与扩容。公开数据继续拥有自身存储。

保留 Adler-32、窗口与距离、截断和累计解压额度检查，未选变量仍完整验证。新增长码、末尾短码、窗口隔离、尾随字节和未选压缩根的回归。

新增固定提交对照入口 `scripts/performance-revisions.py`，记录 native、JS 的全部样本、分批耗时、吞吐、输出大小和独立进程峰值。结果见 [性能报告](PERFORMANCE.md)。

继续提供完整混合树精确比较、无损快照、三种编译目标及独立科研工具验证。

固定 16 MiB 压缩随机数据对照 v0.0.9：native 核心读取提速 3.476 倍，进程峰值下降 22.7%；js 核心读取提速 3.556 倍，进程峰值下降 82.7%。完整数据及目标逐项结果见性能报告。
