# MoonMatBridge v0.0.7

将未压缩写入改为完整预检后一次分配固定缓冲，密集、CSC 和递归混合树共用底层实现，避免逐层临时缓冲及最后一次整文件复制。压缩路径也减少中间复制。

输出缓冲完全由内部独占，写入结束后转移为不可变字节，不保留可修改别名。类型、维度、字段顺序、IEEE 原始位、精确整数、稀疏存储和错误限额继续验证。

性能报告以同机、同工具链的 v0.0.5 为对照，分别列出 native / JS 核心计时、命令行总耗时和峰值内存；未达目标或出现退化的项目如实列出。公开验证与实际科研工具回执随发行提供。

安装：`moon add WeiR-h/moonmatbridge@0.0.7`。完整标准变体终点仍在推进，保持 0.x。
