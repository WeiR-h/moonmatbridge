# MoonMatBridge v0.0.6

本版完善科研文件交换的兼容证据，并建立后续性能优化的固定对照。

- 全部 15 个公开基本类的独立混合文件矩阵：大小端、压缩/未压缩、native/JS，共 8 组；包含多维、空数组与交叉嵌套。
- 真实 GNU Octave v6/v7 生产和消费验证；修复空格 subsystem 字段、nonsparse 保留字 1，并使用跨工具一致的 struct 字段宽度小数据标签。
- Octave 8.4 的短字符矩阵和 sparse logical 生产者变体保留为独立案例，未解决项单列，不计为通过。
- 固定 v0.0.5 源码与同机工具链，记录原始计时、CLI 总耗时、进程峰值内存和输入哈希；本版不预先宣称性能目标已达到。

核心保持 MoonBit 原生实现，无新增产品运行时依赖。MATLAB 实际执行及主办方验收仍单独跟踪，完整标准变体终点未达前保持 0.x。

验证报告和可下载混合文件随版本提供。安装：`moon add WeiR-h/moonmatbridge@0.0.6`。
